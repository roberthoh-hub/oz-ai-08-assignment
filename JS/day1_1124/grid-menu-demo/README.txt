[Grid로 숨긴 영역 펼치기 데모]

■ 실행 방법
  index.html 파일을 더블클릭하면 브라우저(Chrome, Edge, Safari 등)에서 열립니다.
  (Windows: zip을 먼저 "압축 풀기"한 다음 여시면 됩니다.)

■ 내용
  데모 1. 햄버거 메뉴: PC는 hover, 모바일은 클릭 (grid-template-rows 0fr → 1fr)
  데모 2. Grid Garden 26단계처럼 repeat(3, 0)으로 행을 숨겼다가 펼치기
  데모 3. 자주 하는 실수: overflow: hidden을 빠뜨린 경우

■ 코드 보기
  index.html을 메모장, VS Code 등으로 열면 CSS, JS와 주석을 모두 볼 수 있습니다.
  (파일 하나에 HTML/CSS/JS가 모두 들어 있습니다.)
