Grid로 숨긴 영역 펼치기 데모

Grid Garden 26단계 repeat(3, 0) 원리를 실무 UI에 적용해 보기

데모 1. 햄버거 메뉴: PC는 hover, 모바일은 클릭

  • 홈
  • 팀 소개
  • 프로젝트
  • 문의하기

✔ PC에서 버튼에 마우스를 올리면 펼쳐집니다.
✔ 모바일이나 클릭할 때도 열리고 닫힙니다(바깥을 누르거나 Esc를 눌러도 닫힘).
✔ 키보드 Tab으로 이동해도 열립니다(:focus-within). 

.menu__panel {
  display: grid;
  grid-template-rows: 0fr;         /* 접힌 상태 */
  transition: grid-template-rows .3s ease;
}
.menu__inner { overflow: hidden; min-height: 0; }  /* 필수 */

@media (hover: hover) {            /* 마우스가 있는 기기에서만 */
  .menu:hover .menu__panel { grid-template-rows: 1fr; }
}
.menu.open .menu__panel { grid-template-rows: 1fr; } /* 클릭용 */

💡 height: auto에는 transition이 걸리지 않지만, 0fr → 1fr은 애니메이션이 됩니다. 내용 높이를 몰라도 부드럽게 펼쳐지는 것이 핵심입니다.

데모 2. Grid Garden처럼 repeat(3, 0)으로 행 숨겼다가 펼치기

1행: 50px (흙)
2행: 숨겨진 필터 영역
3행: 숨겨진 알림 배너
4행: 숨겨진 추가 옵션
5행: 1fr (물, 남은 공간 전부)
.garden { grid-template-rows: 50px repeat(3, 0) 1fr; }        /* 기본: 2~4행 높이 0 */
.garden.show { grid-template-rows: 50px repeat(3, 50px) 1fr; } /* 펼침 */

💡 행 번호(1~5)는 그대로 두고 공간만 0으로 만듭니다. 그래서 5행 요소의 grid-row: 5 / 6 설정을 바꾸지 않아도 됩니다. 대시보드의 필터 패널이나 공지 배너처럼 "조건에 따라 보이는 영역"에 쓰기 좋습니다.

데모 3. 자주 하는 실수: overflow: hidden을 빠뜨린 경우

두 상자 모두 grid-template-rows: 0fr(높이 0)입니다.

❌ overflow 없음

행 높이는 0인데 글자가 밖으로 삐져나와서 그대로 보입니다. 숨긴 게 아닙니다!

✅ overflow: hidden

이 글자는 제대로 숨겨져서 보이지 않습니다.
